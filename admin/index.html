Admin tools

Everything for running the Medical Premium Illustrator. Each tool asks you to sign in, and signing in on one carries across to the rest.

Agents
See every verified agent and the Terms they accepted. Revoke someone's access — it takes effect on their very next request.
Usage & Activity
How many illustrations by product, plan and agent — and a record of which admin changed what.
Branding
Company name, product name, colours and contact details, with a live preview.
Rate Import
Add a new product from an Excel rate workbook — check a preview, then publish.

First time? Three things to know

  1. The backend must be running. Locally, that's npm start inside the backend folder. Each tool has a Backend URL bar at the top — leave it blank for a local backend, or paste your live address (e.g. https://your-app.onrender.com) once.
  2. Create your admin account. Set ADMIN_BOOTSTRAP_USERNAME and ADMIN_BOOTSTRAP_PASSWORD on the backend and restart it once; your account is created automatically. Then sign in with those details. Until you do, the legacy ADMIN_SECRET still works.
  3. Sign out on shared computers. Staying signed in is remembered in this browser.
